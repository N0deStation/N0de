# NodeStation

An autonomous ground station that lands drones, swaps their batteries mechanically, and recharges the used packs, so drone fleets can keep operating without human intervention.

- **Course:** CPE 423, Stevens Institute of Technology, Fall 2026 – Spring 2027
- **Advisor / sponsor:** Ying Wang
- **Project site:** https://n0destation.github.io/N0de/ (served from the [`docs/`](docs/) folder via GitHub Pages)
